# Sources and synthesis

- [oh-my-pi PR #18580 review comment](https://github.com/can1357/oh-my-pi/pull/18580#discussion_r4509995360), code commit `6192adbdd6fde40fa71526cd8eb17587d057541c`: an example of connecting a concrete input and two code paths to a credential inconsistency. It illustrates an evidence chain, not independent proof that this Pack detects the issue.
- [OpenCodeReview architecture](https://github.com/alibaba/open-code-review/blob/5c4c948c0ecb18715c00997f6bde238745605274/pages/src/content/docs/en/architecture.md) and [review rules](https://github.com/alibaba/open-code-review/blob/5c4c948c0ecb18715c00997f6bde238745605274/pages/src/content/docs/en/review-rules.md): contextual grouping, file selection and locating comments inform coverage and evidence practices. Its parallel review subtasks are not adopted: this Pack requires the specified reviewer to perform substantive judgments personally. Rules are not copied as binding repository contracts.
- [OpenCodeReview file selection](https://github.com/alibaba/open-code-review/blob/5c4c948c0ecb18715c00997f6bde238745605274/internal/agent/selection.go), [Apache-2.0 license](https://github.com/alibaba/open-code-review/blob/5c4c948c0ecb18715c00997f6bde238745605274/LICENSE): motivates giving the reviewer relevant evidence at the point of judgment. The Pack does not copy OCR code or rules, select source files, start workers, or publish comments.
- [AACR-Bench dataset](https://huggingface.co/datasets/Alibaba-Aone/aacr-bench/tree/47be1d6df1e7faf222cf531587772d92f79fe6b2): the Apache-2.0 dataset card describes 2,145 comments (1,505 correct, 640 incorrect) for comment reflection. The labels do not establish all defects in the source diff or prove detection from scratch. Source repository code has separate licensing; record it at the selected revision rather than inferring it from the dataset license.

The execution contract and Practices synthesize the user requirements and these references. Benchmark scores, review quality, actual model routing and behavior are not established by these sources.
