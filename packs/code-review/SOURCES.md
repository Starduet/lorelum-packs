# Sources and synthesis

- [oh-my-pi PR #18580 review comment](https://github.com/can1357/oh-my-pi/pull/18580#discussion_r4509995360), code commit `6192adbdd6fde40fa71526cd8eb17587d057541c`: an example of connecting a concrete input and two code paths to a credential inconsistency. It illustrates an evidence chain, not independent proof that this Pack detects the issue.
- [OpenCodeReview architecture](https://github.com/alibaba/open-code-review/blob/5c4c948c0ecb18715c00997f6bde238745605274/pages/src/content/docs/en/architecture.md) and [review rules](https://github.com/alibaba/open-code-review/blob/5c4c948c0ecb18715c00997f6bde238745605274/pages/src/content/docs/en/review-rules.md): contextual grouping, file selection and locating comments inform coverage and evidence practices. Its parallel review subtasks are not adopted: this Pack requires the specified reviewer to perform substantive judgments personally. Rules are not copied as binding repository contracts.
- [AACR-Bench dataset](https://huggingface.co/datasets/Alibaba-Aone/aacr-bench/tree/47be1d6df1e7faf222cf531587772d92f79fe6b2): the dataset card describes 2,145 labeled review comments for reflection, including correct and incorrect comments. It is a source of candidate cases, not an infallible oracle or proof of finding defects from scratch. Check the pinned code, contract, location and label independently before using any case. This Pack's initial evaluation cases are synthetic, not claimed to originate from this dataset.

The execution contract and eight failure-mode Practices are original synthesis of the user requirements and these references. Benchmark scores, review quality, actual model routing and behavior are not established by these sources.
