# Bug report issue template

Copy this skeleton to the task workspace and fill it in; adapt it to the repository's own template
when one exists. Write in the repository's collaboration language; paste logs and commands
verbatim, sanitized of any private values.

**Title:** `<what behaves unexpectedly>`

## What happened?

A clear description of the unexpected behavior.

> When I ran `<command>`, I expected X but got Y.

## Steps to reproduce

Minimal, ordered, reproducible steps. The more precise, the faster the fix.

1. `<command or action>`
2. `<command or action>`
3. Observe the error

## Expected behavior

What should have happened instead.

## Version and environment

- Version: `<output of the project's --version, or the commit hash>`
- Environment: `<OS / runtime + version / relevant tool>`

## Logs / error output

Paste relevant logs or stack traces as text (no screenshots of text). Replace internal hostnames,
tokens, and personal data with synthetic placeholders before posting.

## Confirmation

- [ ] I searched existing issues and this is not a duplicate.
